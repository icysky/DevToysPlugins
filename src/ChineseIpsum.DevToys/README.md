# ChineseIpsum.DevToys

DevToys 扩展：**中文假文生成器**。提供两种模式——四大名著节选（有语义），
以及按规则生成的**随机乱文**（完全无意义，专门用来测排版）。

NuGet 包：<https://www.nuget.org/packages/ChineseIpsum.DevToys>　·　安装：DevToys → 设置 → 扩展 → 搜索「假文」或 `lorem`。

## 功能

**模式一：名著节选**（有语义的占位文本）

- **语料**：红楼梦 / 西游记 / 水浒传 / 三国演义 / 四大名著混合
- **类型**：段落 / 句子 / 字数
- **数量**：1 ~ 5000（段落=段落数，句子=句子数，字数=目标汉字数）
- **每段句子数**：段落类型下可指定范围 N~M（含端点），每段在这个区间内随机
- **以原著开篇起句**：首句固定为该书的著名开头，相当于 `Lorem ipsum dolor sit amet`

**模式二：随机乱文**（无意义，用于测试布局）

- **随机汉字**：从 CJK 基本区随机取字，不使用任何语料
- **包含生僻字**：额外混入 CJK 扩展区（Ext A / Ext B / 基本区尾部）的少见字符
- **模拟文章段落**：段间空行；关闭则输出连续的一段
- **每段句子数**：范围 N~M（含端点），仅开启「模拟文章段落」时生效
- **包含标点符号**：句末用句号 / 感叹号 / 问号，句中随机插入逗号；关闭则纯文字
- **多语言混合**：随机插入英文 / 西里尔 / 希腊文的伪单词，长度从两三个字母到十几个不等，
  还会混入首字母大写、带数字、带连字符的形态（**全部无意义**，只为覆盖不同宽度与换行情况）
- **长度计量**：可选「字符数」（汉字、外文字母、标点都算，空白不算）或「字词数」
  （一个汉字算 1 个词、一个外文单词算 1 个词，标点不算），数量 1 ~ 5000

其他：

- 改任意选项立刻重新生成，输出框右上角「换一批」可重新抽
- 生成结果只读，可直接用输出框自带的复制按钮取走
- 所有选项记忆在 DevToys 设置里，下次打开保持

## 语料说明（仅名著模式）

`Assets/Corpus/*.txt` 每行一句，共约 120 句，取自：

| 文件 | 出处 | 首句（开篇） |
| --- | --- | --- |
| `sanguoyanyi.txt` | 三国演义 | 话说天下大势，分久必合，合久必分。 |
| `xiyouji.txt` | 西游记 | 诗曰：混沌未分天地乱，茫茫渺渺无人见。 |
| `shuihuzhuan.txt` | 水浒传 | 试看书林隐处，几多俊逸儒流。 |
| `hongloumeng.txt` | 红楼梦 | 此开卷第一回也。 |

这些都是明代 / 清代作品，早已进入公有领域。文本是**节选整理**，用于占位文本，
可能有个别字句与通行本不同，不追求校勘级准确。

## 生成规则

**名著模式**

- **段落**：N 段，每段句数在「每段句子数」范围内随机，段间空行
- **句子**：N 句连续成文
- **字数**：按句子累加到不少于 N 个汉字（会略微超出，因为不截断句子）
- 中文句子之间不加空格直接拼接；相邻两句保证不重复

**随机乱文模式**

- 每句 6~17 个汉字，达到目标长度后停止（同样会略微超出，不截断句子）
- 段落模式下每段句数由「每段句子数」范围决定；最后一段可能因为已达目标长度而变短
- 生僻字开关关闭时，只取 CJK 基本区（U+4E00–U+9FA5）
- 外文单词按「辅音 + 元音」音节拼装，因此没有任何语义，也不含真实词汇
- 同一台机器上每次生成都不同（使用进程级随机数）

## 用途与注意

随机乱文不包含任何真实语义，适合：

- 验证字号、行高、字间距、断行与标点避头尾等排版效果
- 测试长文滚动、富文本渲染、导出 PDF / 图片时的分页
- 演示界面时避免使用真实业务文案

> 该模式下会故意混入生僻字与多语言字符，**不要**用它做文本处理或字体覆盖率的正确性判断。
