# ChineseIpsum.DevToys

DevToys 扩展：**中文假文生成器**。提供两种模式——四大名著节选（有语义），
以及按规则生成的**随机乱文**（完全无意义，专门用来测排版）。

NuGet 包：<https://www.nuget.org/packages/ChineseIpsum.DevToys>　·　安装：DevToys → 设置 → 扩展 → 搜索「假文」或 `lorem`。

## 功能

**模式一：名著节选**（有语义的占位文本）

- **语料**：红楼梦 / 西游记 / 水浒传 / 三国演义 / 四大名著混合
- **类型**：段落 / 句子 / 字数
- **数量**：1 ~ 5000（段落=段落数，句子=句子数，字数=目标汉字数）
- **每段句子数**：段落类型下可指定范围 N~M（含端点），每段在这个区间内随机
- **段落间空行**：开启时段落之间空一行（默认），关闭则只用单个换行分隔
- **以原著开篇起句**：首句固定为该书的著名开头，相当于 `Lorem ipsum dolor sit amet`

**模式二：随机乱文**（无意义，用于测试布局）

- **随机汉字**：从常用字表随机取字，不使用任何语料
- **模拟文章段落**：关闭则输出连续的一段
- **每段句子数**：范围 N~M（含端点），仅开启「模拟文章段落」时生效
- **段落间空行**：开启时段落之间空一行（默认），关闭则只用单个换行分隔
- **包含生僻字**：开启后混入 GB2312 二级字（3008 个次常用/生僻字）与 CJK 扩展区字符；
  关闭时**只用 GB2312 一级字表（3755 个常用字）**，不会再出现满屏怪字
- **包含标点符号**：关闭则纯文字；开启后句末、句中、成对符号都会出现
- **标点风格**：中文标点（，。！？…、；：（）《》「」“”【】·～）／西文标点（, . ! ? ; : ( ) [ ] { } " ' @ # % & * + = / \ | 等）／两者混用；
  句末偶尔连用（？！、…！），也会混入单个符号，方便观察不同字形的宽度与避头尾
- **多语言混合**：随机插入英文 / 西里尔 / 希腊文的伪单词，长度从两三个字母到十几个不等，
  还会混入首字母大写、带数字、带连字符的形态；其中约五分之一的词是**按规则生成的缩写**
  （`S.A.`、`N.V.`、`LLC`、`A & B`、`AB-1024` 这类机构/公司后缀形态）——同样不查表、纯规则拼装，
  用来覆盖大写字母、间隔句点、与号、连字符的排版（**全部无意义**）
- **长度计量**：可选「字符数」（汉字、外文字母、标点都算，空白不算）或「字词数」
  （一个汉字算 1 个词、一个外文单词算 1 个词，标点不算），数量 1 ~ 5000

**字符压力**（默认全关，勾选后才混入，用来暴露字体回退与断行问题）

| 选项 | 混入内容 | 能暴露什么 |
| --- | --- | --- |
| Emoji | 😀 🚀 👍🏽 👨‍👩‍👧‍👦 🇨🇳 | 彩字宽度、行高、ZWJ 组合被拆开 |
| 日文 / 韩文 | ひらがな・カタカナ・한글 | 中日韩字体回退顺序 |
| RTL 文字 | 阿拉伯文 / 希伯来文 | BiDi 混排、括号镜像、`dir=auto` |
| 数学与符号 | ∑ ∫ √ ≤ → ↔ ┌┬┐ • † ※ | 符号字体缺失（豆腐块） |
| 拉丁扩展 | é ü ñ ç ß + 组合音标 | 变音符号与字体合成 |
| 特殊数字与单位 | ¹²³ ½ ① Ⅰ ¥ ℃ ㎡ ‰ | 上标下标撑行高、货币/单位宽度 |
| 全角字符 | ＡＢＣ１２３ | 中西文混排间距、等宽对齐 |
| 不可见字符 | NBSP / 零宽空格 / 软连字符 / LRM | 断行行为、复制粘贴异常 |
| 超长不可断串 | 40~200 个连续字母 | `overflow-wrap` / `word-break` 缺失 |

**结构化片段**（有格式、无意义，用于测表单 / 列表 / 卡片）

URL（`https://…?id=…`）、邮箱、UUID / 哈希（32·40·64 位 hex）、版本号（`v1.2.3-beta.4+build.567`）、
日期时间、金额数值（`1,234,567.89`、`99.99%`、`12,345 kg`）、文件路径（`/var/www/a/b/file.tar.gz`）。

**段落形态**

- **段落长短**：短段多 / 混合 / 长段多（以「每段句子数」为基准上下浮动）
- **标点密度**：低 / 中 / 高（句中逗号的密集程度）
- **空格策略**：无 / 单 / 多（外文词前的空格）
- **首行缩进**：段首加两个全角空格
- **列表符号**：不加 / 项目符号 `•` / 有序编号 `1.`
- **引用块**：段首加 `> `
- **行内代码**：偶尔把词包成 `` `code` ``

其他：

- 改任意选项立刻重新生成，输出框右上角「换一批」可重新抽
- 生成结果只读，可直接用输出框自带的复制按钮取走
- 所有选项记忆在 DevToys 设置里，下次打开保持

## 语料说明（仅名著模式）

`Assets/Corpus/*.txt` 每行一句，共约 120 句，取自：

| 文件 | 出处 | 首句（开篇） |
| --- | --- | --- |
| `sanguoyanyi.txt` | 三国演义 | 话说天下大势，分久必合，合久必分。 |
| `xiyouji.txt` | 西游记 | 诗曰：混沌未分天地乱，茫茫渺渺无人见。 |
| `shuihuzhuan.txt` | 水浒传 | 试看书林隐处，几多俊逸儒流。 |
| `hongloumeng.txt` | 红楼梦 | 此开卷第一回也。 |

这些都是明代 / 清代作品，早已进入公有领域。文本是**节选整理**，用于占位文本，
可能有个别字句与通行本不同，不追求校勘级准确。

## 生成规则

**名著模式**

- **段落**：N 段，每段句数在「每段句子数」范围内随机，段间空行
- **句子**：N 句连续成文
- **字数**：按句子累加到不少于 N 个汉字（会略微超出，因为不截断句子）
- 中文句子之间不加空格直接拼接；相邻两句保证不重复

**随机乱文模式**

- 每句 6~17 个汉字，达到目标长度后停止（同样会略微超出，不截断句子）
- 段落模式下每段句数由「每段句子数」范围决定；最后一段可能因为已达目标长度而变短
- 字表按 GB2312 分区：常用字 = 一级汉字（3755 个），生僻字 = 二级汉字（3008 个）+ CJK 扩展区；
  关闭开关时只从一级字表取字（没有内置字表文件，靠码表分区得到）
- 外文单词按「辅音 + 元音」音节拼装，因此没有任何语义，也不含真实词汇
- 同一台机器上每次生成都不同（使用进程级随机数）

## 用途与注意

随机乱文不包含任何真实语义，适合：

- 验证字号、行高、字间距、断行与标点避头尾等排版效果
- 测试长文滚动、富文本渲染、导出 PDF / 图片时的分页
- 演示界面时避免使用真实业务文案

> 该模式下会故意混入生僻字与多语言字符，**不要**用它做文本处理或字体覆盖率的正确性判断。
