# Cron 表达式（DevToys 扩展）

DevToys 的 Cron 表达式生成器 + 解析器。左边按字段拼出表达式，右边实时显示中文描述与接下来的执行时间。

## 功能

**生成器**：按「秒 / 分 / 时 / 日 / 月 / 周」逐字段选择

- 每个字段都可选「每个值（`*`）」「间隔（`*/n`）」「指定值」
- 「日」额外支持 Quartz 写法：`L`（当月最后一天）、`LW`（当月最后一个工作日）、`15W`（最接近 15 日的工作日）
- 「周」支持 `?`（交给「日」判断）、工作日、周末、`5#2`（第 2 个周五）、`5L`（最后一个周五）
- 「包含秒数」开关决定生成 5 段（分 时 日 月 周）还是 6 段（秒 分 时 日 月 周）表达式
- 9 个快捷模板：每分钟 / 每 5 分钟 / 每小时 / 每天 9:00 / 每天 0:00 / 工作日 9:00 / 每周一 9:00 / 每月 1 日 / 每年 1 月 1 日
- 生成的表达式可一键复制

**解析预览**：直接粘贴别人的表达式也能用

- 中文描述，例如「工作日 09:30」「每月最后一个周五 12:00」
- 列出接下来 N 次执行时间（默认 5 次，最多 100 次）
- 输出时间格式可改，默认 `yyyy-MM-dd ddd HH:mm:ss`（例如 `2026-11-12 周四 11:27:55`）
- 支持 `@yearly` / `@monthly` / `@weekly` / `@daily` / `@hourly` 等宏

## 支持的语法

| 写法 | 说明 |
| --- | --- |
| `*` | 任意值 |
| `5` | 单值 |
| `1,15` | 列表 |
| `1-5` | 范围 |
| `*/10`、`0-30/5`、`5/15` | 步长 |
| `JAN`~`DEC` | 月份名称 |
| `SUN`~`SAT` | 星期名称（`0` 和 `7` 都表示周日） |
| `?` | 仅「日」「周」，表示不参与判断（Quartz） |
| `L` / `LW` / `15W` | 仅「日」（Quartz） |
| `5#2` / `5L` | 仅「周」（Quartz） |

「日」和「周」同时受限时按标准 cron 的「或」语义：满足任一条件即触发。

## 安装

在 DevToys 中：**设置 → 扩展（Manage extensions）** → 搜索「Cron」或标签 `devtoys-app` → 安装 → 重启 DevToys。

工具位于左侧 **生成器（Generators）** 分组，名为「Cron 表达式」。

## 许可

插件代码采用 **0BSD**。不依赖任何第三方运行库。
