# 编码转换台（DevToys 扩展）

把日常开发里零散的编码 / 进制转换收进一个工具：左侧切换模式，右侧一次输入，下面同时列出 Hex、Base64、Unicode 码点等辅助视图。数据处理全部在本机完成，不联网。

## 功能

| 模式 | 说明 |
| --- | --- |
| URL 组件 | URL 组件编码/解码；可切换表单模式（`+` 表示空格），非法 `%` 序列会明确报错 |
| HTML 实体 | `< > & " '` 与 `&lt;` / `&#xNN;` / `&#NNN;` 互转 |
| Unicode 转义 | `\uXXXX`、`\xNN`、`%uXXXX`、`U+XXXXX` 互转，Emoji 代理对正确处理 |
| JSON 字符串 | 字符串内部转义/反转义，支持 `\n`、`\t`、`\uXXXX` 与代理对 |
| Base64 / Base64url | 标准字母表与 URL 安全字母表，可切换是否保留 `=` 填充，解码自动忽略换行 |
| Base32 / Base58 | RFC 4648 Base32、Bitcoin Base58（不含 `0`、`O`、`I`、`l`） |
| Hex 字节 | 文本 ⇄ Hex，可选大写/小写与分隔符 |
| 字符集转码 | UTF-8 / GB18030 / UTF-16LE / UTF-16BE / ASCII，可选 BOM |
| 进制互转 | 2~36 进制，支持负数、`0x`/`0b`/`0o` 前缀、任意精度整数 |
| 补码 / 字节序 | 8/16/32/64 位补码，有符号/无符号，大端/小端 |
| IPv4 地址 | IPv4 ⇄ 32 位整数，同时给出网络序与主机序 |
| Unix 时间戳 | 秒 / 毫秒 / 微秒 / 纳秒与日期互转，可指定 UTC 或本地时区 |
| GUID 格式 | N / D / B / P / X 五种格式与两种字节序 |

**辅助视图**：每次转换都会在下方并列显示相关表示，例如「UTF-8 字节 Hex」「Base64」「Unicode 码点」「二进制」「有符号/无符号十进制」等。不用在不同工具之间来回复制。

**链式转换**：勾选二次解码，可做 `Base64 解码 → URL 解码` 这类组合操作。

**选项随模式显隐**：只有当前模式用得到的参数会出现在左侧，避免一屏全是无关开关。模式、字符集、选项和最近输入会保存在 DevToys 设置里。

## 示例

- `a b&c=中文` → URL 编码 → `a%20b%26c%3D%E4%B8%AD%E6%96%87`
- `中文` → Base64（UTF-8）→ `5Lit5paH`
- `😀` → Unicode → `\uD83D\uDE00`
- `255` → 10 进制转 2 进制 → `11111111`
- `192.168.1.1` → IPv4 编码 → `3232235777`
- `1970-01-01T00:00:00Z` → 时间戳（秒）→ `0`

## 安装

在 DevToys 中：**设置 → 扩展（Manage extensions）** → 搜索「编码转换台」或标签 `devtoys-app` → 安装 → 重启 DevToys。

工具位于左侧 **编码/解码（Encoders & Decoders）** 分组，名为「编码转换台」。

## 许可

插件代码采用 **0BSD**。不依赖任何第三方运行库。
